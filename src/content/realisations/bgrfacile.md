bgrfacile est parti d’une idée simple : aider les élèves congolais à trouver
des cours et des contenus scolaires en ligne. Le projet a ensuite grandi vers
les écoles elles-mêmes, avec des outils pour gérer les élèves, les cours et la
vie de l’établissement.

Je l’ai mené à temps partiel, de 2019 à 2025, à côté de mes emplois et de mes
études. Le code public retrace surtout ses dernières versions, de 2022 à 2024 :

- un site en Laravel et React (relié par Inertia), avec une base MySQL ;
- une API Laravel « multi-écoles » : chaque école a ses propres données,
  séparées des autres. Elle est documentée en OpenAPI et protégée par une
  authentification à jeton ;
- quelques tests automatisés (Pest), lancés par GitHub Actions sur une vraie
  base MySQL à chaque modification ;
- deux interfaces en React et TypeScript : une application pour les écoles et
  un outil d’administration.

Une application Android en Flutter a aussi été publiée sur le Play Store ; elle
en a été retirée depuis.

Le projet est arrêté depuis 2025 et le site n’est plus en ligne. Le code, lui,
reste public.
