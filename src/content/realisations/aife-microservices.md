## Le contexte

À l’AIFE (l’Agence pour l’informatique financière de l’État), j’ai rejoint une
équipe backend de 10 personnes. Elle travaillait avec plusieurs autres équipes
Capgemini et un partenaire externe. Le projet suivait SAFe, une méthode agile
pensée pour faire travailler beaucoup d’équipes ensemble.

## Ce que j’ai fait

J’ai développé des **microservices Java / Spring Boot** : API REST, SQL, tests
unitaires JUnit. J’ai aussi pris part à la vie de l’équipe : PI planning,
estimations, revues de code et démonstrations au client.

Ensuite, j’ai rejoint un projet dans l’aviation, dans une équipe agile de 8.
Nous avons conçu un outil qui traite de gros volumes de documents PDF, avec
une recherche assistée par IA, sur **AWS** (Python, Lambda, S3, PostgreSQL).
Tickets, pair programming et revues de pull requests faisaient partie du
quotidien.
