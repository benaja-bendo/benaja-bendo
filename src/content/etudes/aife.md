## Le contexte

Au sein de l’AIFE (finances publiques), j’ai intégré une équipe backend de 10
personnes, coordonnée avec plusieurs équipes Capgemini et un partenaire externe,
en agilité à l’échelle.

## Ce que j’ai fait

J’ai développé des **microservices Java / Spring Boot** : API REST, SQL, tests
unitaires JUnit, PI planning, estimations, revues de code et démonstrations client.

J’ai ensuite participé à un projet aviation dans une équipe agile de 8 : conception
d’un outil de traitement de gros volumes de documents PDF avec recherche assistée
par IA sur **AWS** (Python, Lambda, S3, PostgreSQL), avec tickets, pair programming
et revues de pull requests.
